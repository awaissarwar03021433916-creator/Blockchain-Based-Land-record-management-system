# 🚀 ChainPlot - Blockchain-Based Land Record Management System

A secure and transparent Blockchain-Based Land Record Management System developed as a Final Year Project. ChainPlot leverages blockchain technology to create immutable land ownership records, enabling secure property transfers while reducing fraud and improving trust in digital land management.

---

## 📖 Project Overview

Traditional land record systems often rely on paper-based documentation, making them vulnerable to fraud, duplication, and ownership disputes.

ChainPlot solves these challenges by integrating Blockchain technology with a modern web application, ensuring secure ownership verification, transparent record management, and tamper-resistant property transfers.

---

## ✨ Features

- 🔐 Secure User Authentication (JWT + Bcrypt)
- 👤 Role-Based Access Control (Admin, Owner, Buyer)
- 🏡 Land Registration
- 🔄 Secure Ownership Transfer
- ⛓ Blockchain-Based Ownership Verification
- 📜 Immutable Transaction History
- 📊 Admin Dashboard
- 👥 Buyer & Owner Dashboards

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/awaissarwar03021433916-creator/Blockchain-Based-Land-record-management-system.git
```

### Install Dependencies

```bash
npm install
```

### Start Backend

```bash
cd server
npm install
npm run dev
```

### Start Frontend

```bash
cd client
npm install
npm run dev
```

### Run Blockchain

```bash
cd blockchain
truffle migrate
```
